    Import a private playlist

    Spotify doesn't let anyone see private playlists or your Liked Songs, so a link won't work for those. Exportify is a free site that signs into your Spotify and exports any playlist as a CSV file — Yoink reads that file (or any CSV with a Track URI column). You can also drop a CSV anywhere on this page.
    1. Open exportify.net and log in with Spotify.
    2. Click Export next to the playlist (or Liked Songs).
    3. Drop the CSV below.
